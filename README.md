# Yacht Dice 화투패

iOS 게임 허브 앱 "요트 다이스"의 맞고에 쓰는 화투 그림 묶음이다. 앞면 48장은 위키미디어 공용의 [Hwatu_overview.svg](https://commons.wikimedia.org/wiki/File:Hwatu_overview.svg)(Marcus Richert, Louie Mantia, Jr.의 도안 기반)를 다듬은 파생물이고, 뒷면은 Yacht Dice project가 새로 그렸으며, 모두 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ko)으로 DRM 없이 제공한다.

> 화투: Marcus Richert(Louie Mantia, Jr.의 도안 기반), 위키미디어 공용 · Yacht Dice project 수정 · CC BY-SA 4.0. 뒷면: Yacht Dice project · CC BY-SA 4.0.

- `cards/`: 앞면 48장과 뒷면의 SVG이며, 수정 범위와 출처는 [cards/LICENSE.md](cards/LICENSE.md)에 있다.
- `cards-export/`: 앱에 넣은 PNG(@2x 92×144px, @3x 138×216px)다.
- `refs/commons/`: 원본 SVG와 대조용 월별 SVG이며, 파일별 작가·날짜·주소·검증값은 [ATTRIBUTION.md](refs/commons/ATTRIBUTION.md)에 있다.
- `LICENSE`: CC BY-SA 4.0 전문이다.

이 표기는 원작자의 앱 보증이나 후원을 뜻하지 않는다.
